# [계정 이름] 형식 (F01~)

대표대본을 구조가 같은 것끼리 묶어 형식으로 정리한다. 대표대본 전건이 빠짐없이 한 형식에 배정되고, 중복 배정은 없다.
초 단위 흐름은 대본 문장 순서와 첫 3초 시각분석에서 뽑는다. 추정한 초는 넣지 않는다.
"궁합 훅"의 H 번호는 훅.md와 같은 번호를 가리킨다.

> 채우는 법: `/계정세팅`이 대표대본을 군집해 초안을 쓴다. 형식 하나에는 해당 대표대본 2건 이상이 있어야 한다. 1건짜리는 형식이 아니라 사례다.

## 추가 방법

새 형식을 넣을 때는 다음 네 가지가 모두 있어야 한다.

1. 해당 대표대본 2건 이상 (조회 수치 포함)
2. 초 단위 흐름을 대본 문장 순서에서 뽑은 근거
3. 궁합 훅 번호. 훅.md에 없는 훅이면 훅.md부터 추가한다
4. 대본 길이 실측 (공백 제외 최소~최대, 발화 중심인지 자막 중심인지). SKILL.md 3단계가 이 줄을 참조한다

기존 형식에 새 대본을 추가할 때는 해당 대표대본 줄에 M-###와 조회를 넣고 중앙 조회와 대본 길이 범위를 다시 계산한다.
