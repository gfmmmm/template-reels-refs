# 릴스 레퍼런스 수집기 (템플릿)

> 이 저장소는 **누구나 복사해서 자기 계정용으로 쓰는 템플릿**이에요. 개인 데이터는 하나도 없어요.
> 받는 법: 초록 **"Use this template" → Create a new repository**(비공개 권장) 를 누르거나, 그냥 ZIP 으로 받아 폴더로 풀어요.
> 세팅은 그 폴더에서 Claude Code 를 열고 **"세팅 가이드대로 진행해줘"** 라고 하면 돼요 — Claude 가 `SETUP.md` 를 읽고 키 넣기 → 계정 등록 → 첫 수집 → AI 분석 → 기획 스킬 → (원하면) 클라우드 자동화까지 이끌어요.
> 사람이 직접 읽을 설명은 아래 1~10절.


내 컴퓨터 안에서만 도는 작은 웹페이지예요. 인터넷에 올라가지 않아요.

- **레퍼런스 탭**: 내가 등록한 계정들의 릴스 중 "기준 조회수 이상으로 터진 것"만 모아서 보여줘요. 카드를 누르면 화면 가운데에 팝업이 뜨고, 거기서 인스타 영상이 바로 재생돼요. 릴스마다 `#R-001` 같은 고유 라벨이 붙어요. AI 분석(2단계)이 끝난 릴스는 "왜 터졌나"와 "내 콘텐츠에 이렇게(차용포인트)"까지 팝업에 나와요.
- **내 계정 & 경쟁사 탭**: 내 프로필·팔로워 추이·내 릴스 카드(옆으로 넘김), 그리고 경쟁사 계정과의 업로드 수·평균 조회수·팔로워 증감률 순위표와 팔로워 추이 그래프.
- **설정 탭**: 레퍼런스 계정, 경쟁사 계정, 자동 스냅샷, 기준 조회수, 수집 실행.

## 1. 켜는 법

### 맥
`시작.command` 파일을 **더블클릭**하면 검은 창이 하나 뜨고, 잠시 뒤 브라우저가 자동으로 열려요.

> **"확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 뜨면**
> 1. `시작.command` 파일을 **마우스 오른쪽 클릭 → 열기**를 누르세요. 그러면 "열기" 버튼이 있는 창이 떠요.
> 2. 그래도 안 되면: 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "그래도 열기" 버튼.
> 3. 한 번만 허용하면 다음부터는 그냥 더블클릭으로 열려요.

### 윈도우
`시작.bat` 파일을 **더블클릭**하세요. 파란 "Windows의 PC 보호" 창이 뜨면 "추가 정보 → 실행"을 누르면 돼요.

### 공통
- 검은 창은 **닫지 마세요.** 그 창이 서버예요. 닫으면 웹페이지가 안 열려요.
- 브라우저가 자동으로 안 열리면 주소창에 직접 `http://127.0.0.1:3456` 을 치세요.
- 이미 켜져 있는 상태에서 또 더블클릭하면 "이미 켜져 있어요"라고 알려주고 브라우저만 열어요.
- 끌 때는 검은 창을 닫거나 `Ctrl + C`.

### Node.js 가 없다고 나오면
이 프로그램은 Node.js 라는 무료 프로그램 위에서 돌아가요. https://nodejs.org 에서 **LTS** 버전을 설치한 뒤 다시 더블클릭하세요. 설치 말고는 아무것도 안 해도 돼요 (npm install 같은 것 필요 없음).

## 2. 처음 한 번만 하는 설정

### API 키 넣기
1. https://scrapecreators.com 에 가입하고 API 키를 받아요.
2. 이 폴더의 `.env.example` 파일을 복사해서 이름을 `.env` 로 바꿔요. (이미 `.env` 가 있으면 그냥 열어요)
3. `SCRAPECREATORS_API_KEY=` 뒤에 키를 붙여넣고 저장해요. 따옴표 없이.

> 키는 `.env` 파일에만 있어요. 이 폴더를 남에게 줄 때는 `.env` 를 빼고 주세요.

### 레퍼런스 계정 넣기
설정 탭 → "레퍼런스 계정" 칸에 아이디를 넣고 엔터. `@`나 `instagram.com/` 을 같이 붙여넣어도 알아서 정리돼요.
목록에서 ✕ 를 누르면 빠지는데, 이미 수집된 릴스는 그대로 남아요.

### 경쟁사 계정 넣기
설정 탭 → "경쟁사 계정" 칸에 아이디를 넣고 엔터. 레퍼런스 계정과 겹쳐도 돼요 (겹치면 릴스 목록을 한 번만 받아 크레딧을 아껴요).
"나" 행으로 비교하려면 **내 계정 & 경쟁사 탭** 오른쪽 위 "내 계정" 칸에 내 아이디를 넣고 저장해요. 내 계정을 넣으면 내 릴스 상위 10개의 대본도 함께 받아요(처음 한 번 10크레딧. 설정에서 끌 수 있어요).

### 기준 조회수
기본은 300,000회. 이 숫자 이상인 릴스만 채택돼요. 바꾸면 다음 수집부터 적용.

## 3. 수집 돌리기

설정 탭 → **수집 시작** 버튼. 아래에 진행 로그가 실시간으로 쌓이고, 끝나면 요약이 떠요.

- 처음 보는 계정은 최근 3페이지(약 36개)를 훑어요.
- 이미 본 계정은 새 릴스가 없는 페이지를 만나면 바로 멈춰요 (크레딧 절약).
- 기준에 못 미친 릴스도 기억해 뒀다가 다음 수집 때 조회수가 올라 기준을 넘으면 그때 채택해요.
- 이미 저장된 릴스는 조회수·좋아요·댓글만 새로 갱신돼요 (크레딧 안 씀).
- 채택된 릴스는 썸네일만 내 컴퓨터에 받아 둬요. 영상은 파일로 받지 않고 팝업에서 인스타그램 임베드로 바로 봐요 (인터넷 필요).
- 레퍼런스가 끝나면 내 계정과 경쟁사의 **팔로워 스냅샷**을 찍고 릴스 통계를 갱신해요. 스냅샷은 하루 한 장만 남아요 (같은 날 두 번 돌리면 덮어써요).
- 설정의 "자동 스냅샷"이 켜져 있으면, 서버(검은 창)가 켜져 있는 동안 하루 한 번 팔로워 스냅샷만 자동으로 찍어요. 컴퓨터가 꺼져 있던 날은 비어요.

수집 중엔 버튼이 비활성화돼요. 끝나면 데이터가 자동으로 새로고침돼요.

## 4. 크레딧이 뭔가요

ScrapeCreators 는 요청 1번마다 "크레딧"을 차감해요. 이 프로그램이 쓰는 건 세 가지:

| 무엇 | 크레딧 |
|---|---|
| 계정의 릴스 목록 1페이지 (12개) | 1 |
| 릴스 상세 조회 (캡션이 비어 있을 때만, 드물어요) | 1 |
| 채택된 릴스의 대본 추출 (2분 이하, 음성 있는 영상만) | 1 |
| 경쟁사·내 계정 팔로워 스냅샷 (계정당, 하루 한 번) | 1 |
| 경쟁사 릴스 통계 (계정당 1페이지. 레퍼런스와 겹치면 0) | 1 |

썸네일 다운로드와 팝업의 영상 재생은 크레딧을 쓰지 않아요.

**예상 사용량**
- 처음 수집: 계정 하나당 3크레딧 + 채택된 릴스 하나당 1크레딧. 계정 5개에 채택 10개면 약 25크레딧.
- 그 뒤 매번: 계정 하나당 보통 1크레딧 + 새로 채택된 것만큼. 계정 5개면 5~8크레딧 정도.
- 경쟁사: 수집 한 번에 계정당 1~2크레딧. 자동 스냅샷을 켜 두면 하루에 (경쟁사 + 내 계정) 수만큼 더 써요. 4개 계정이면 한 달 약 120크레딧.

남은 크레딧은 화면 왼쪽 아래에 항상 보여요. 상세한 사용 내역은 수집 끝 요약에 나와요.

## 5. 화면 사용법

**레퍼런스 탭**
- 검색창에 단어를 치면 캡션·대본·라벨·계정을 동시에 찾고, 일치하는 부분이 노란색으로 표시돼요. `R-003` 처럼 라벨로도 찾을 수 있어요.
- 정렬: 조회수 높은순 / 최신순.
- 카드 오른쪽 위 하트 = 찜. "♥ 찜" 버튼으로 모아 볼 수 있어요. (찜은 이 브라우저에만 저장돼요)
- 카드 왼쪽 아래 `#R-001` 이 그 릴스의 고유 라벨이에요. 한 번 붙으면 바뀌지 않으니 메모나 대화에서 "R-001 참고" 처럼 쓰면 돼요.
- **카드를 누르면** 화면 가운데에 팝업이 떠요:
  - 왼쪽: 인스타 영상 (임베드라 바로 재생돼요. 인터넷이 필요해요)
  - 오른쪽: 라벨, 계정, "인스타에서 보기" 버튼 (새 탭), 조회수·좋아요·댓글·길이·업로드일, 캡션 전문, 대본 전문, "캡션+대본 복사" 버튼 (라벨과 주소도 같이 복사돼요)
  - ESC 나 바깥 어두운 곳을 클릭하면 닫혀요.

**내 계정 & 경쟁사 탭**
- 내 프로필 아래 "내 릴스" 상자: 내 릴스 카드가 가로 한 줄로 놓여요. 옆으로 넘겨 보고, 조회수순·최신순으로 바꿀 수 있어요. 카드를 누르면 팝업에서 영상·캡션·대본(상위 10개)이 보여요.
- 오른쪽 위 "내 계정" 칸에 내 아이디를 넣으면 맨 위에 내 프로필 카드(사진·아이디·게시물·팔로워·팔로우·소개·링크·총 조회수·역대 최고)와 내 팔로워 추이 그래프가 뜨고, 순위표에 "나 · 아이디" 행이 들어가고 "내 N위/M" 배지가 붙어요.
- 내 팔로워 추이는 실제 팔로워 수 그대로 그려요. 위에 "-461 기간 증감 · 전체의 1.1% 감소 (8/28 부터)"처럼 첫 스냅샷 대비 변화가 적혀요.
- 업로드 수: 최근 주간·월간·3개월·6개월에 올린 릴스 개수. 받아 둔 목록(계정당 최근 36개 안팎)보다 기간이 넓으면 숫자 뒤에 "+"가 붙어요 (실제는 더 많을 수 있다는 뜻).
- 평균 조회수: 최근 10·20·30개 또는 전체 평균.
- 팔로워 증감률: 최신 스냅샷과 주간·월간·3개월 전 스냅샷을 비교. 스냅샷이 그만큼 안 쌓였으면 첫 스냅샷부터 계산하고 "*"를 붙여요. 스냅샷이 한 장뿐이면 "쌓는 중"이라고 나와요.
- 팔로워 추이: 첫 스냅샷을 0으로 두고 늘어난 수를 선으로 그려요. 점에 마우스를 올리면 날짜와 팔로워 수가 떠요. 검은 선이 나예요.

| 이미 수집이 돌아가고 있어요 | 수집 버튼을 연달아 누름 | 끝날 때까지 기다리기 |

**썸네일이 안 보여요** → 수집 당시 다운로드에 실패한 거예요. 다음 수집 때 다시 받아요.

**수집이 중간에 끊겼어요** → 그때까지 채택된 릴스는 이미 저장돼 있어요. 다시 수집을 누르면 이어서 해요.

## 7. AI 분석 (2단계) — "왜 터졌나 + 차용포인트"

### 준비물: Gemini 키 (무료)
1. https://aistudio.google.com → 로그인 → **Get API key → Create API key**. `AIza` 또는 `AQ.` 로 시작해요.
2. `.env` 파일에 `GEMINI_API_KEY=` 뒤에 붙여넣고 저장. 서버를 껐다 켜요.

### 내 채널 정체성 쓰기
설정 탭 → "AI 분석 — 내 채널 정체성". 누가 운영하는 무슨 채널인지, 타깃, 잘 먹혔던 것, 하지 않을 것을 3~5문장으로. 콘텐츠 기둥은 내 채널 주제 축 3~6개를 쉼표로. 이걸 채워야 "차용포인트"가 내 채널 맞춤으로 나와요. 비워 두면 일반론이 됩니다.

**쓰기 어려우면 "🪄 자동 분석" 버튼.** 경쟁사 탭에 내 계정을 넣고 수집을 한 번 돌린 뒤 누르면, AI 가 내 릴스 27개쯤과 프로필 소개를 읽고 "어떤 채널인가 / 무엇을 주제로 / 잘 되는 것과 저조한 것의 패턴 / 차별점 / 강점과 포지셔닝" 다섯 항목으로 초안을 써서 칸에 채워 줘요. 30초 안팎. **읽어 보고 고친 뒤 "저장"을 눌러야 반영돼요.** 자동으로 저장되지 않아요.

### 분석 돌리기
- 자동: "수집이 끝나면 자동으로 이어서 분석" 체크(기본 켜짐). 수집 → 바로 분석으로 이어져요.
- 수동: 설정 탭 → "분석 시작". 미분석 릴스를 조회수 높은 순으로 최대 20개.
- 한 건: 팝업에서 "지금 이 릴스 분석하기". 이미 분석된 건 "↻ 다시 분석".
릴스 하나에 1~2분 걸려요 (영상을 통째로 AI 에 보여주기 때문). 20개면 30분쯤. 기다리는 동안 다른 탭을 봐도 돼요.

### 인사이트 읽는 법
- **주제**: AI 가 뽑은 한 줄. 카드 제목도 이걸로 바뀌어요.
- **후킹**: 첫 3초에 스크롤을 멈춘 장치. 「」 안이 영상 속 실제 장면·멘트예요.
- **좋은점**: 왜 터졌는지, 메커니즘으로 최대 3개.
- **내 콘텐츠에 이렇게 — 차용포인트**: 내 채널 정체성에 맞춰 번역한, 다음 영상에서 그대로 쓸 수 있는 팁 최대 3개. 검정 테두리 상자.
- **내 채널 관련성**: 높음·중간·낮음. "낮음"은 목록에서 자동으로 숨겨져요(삭제 아님). 툴바의 "숨김 N" 버튼으로 볼 수 있고, 팝업에서 "숨김 해제"할 수 있어요.
- **소구점**: 공구·광고 릴스에만 붙어요. 무엇을 팔며, 어떤 욕구를 찌르고, 어떤 판매 장치를 썼는지.

### 상업성 (일반·공구·광고)
캡션에 #광고·협찬 같은 말이 있으면 광고 📢, 공구·구매 링크 같은 말이 있으면 공구 🛒 로 자동 판정해요. 틀렸으면 팝업의 선택칸에서 고치면 그게 우선이에요. 툴바에서 상업성별로 걸러 볼 수 있어요.

### 비용
- Gemini 는 무료 한도 안에서 돌아요. 한도에 걸리면 "무료 한도에 걸렸어요"라고 멈추니 1분 뒤나 내일 이어서 하면 돼요.
- 영상 주소가 만료된 옛 릴스는 다시 받느라 ScrapeCreators 1크레딧을 써요 (로그에 "영상 주소 재획득"). 수집 직후 바로 분석하면 안 써요.

### 자주 나는 오류
| 화면에 나오는 말 | 이렇게 하세요 |
|---|---|
| .env 에 GEMINI_API_KEY 가 없어요 | 위 준비물대로 키를 넣고 서버를 껐다 켜요 |
| Gemini API 키가 잘못됐어요 | aistudio 에서 키를 다시 복사해 붙여넣기 |
| Gemini 무료 한도에 걸렸어요 | 1분 뒤 다시, 또는 내일 이어서 |
| ❌ 전량 실패 | 인터넷·키·한도 확인. 로그의 이유를 봐요 |
| 3회 실패로 제외 N건 | 같은 릴스가 3번 실패하면 더 안 시도해요. 설정의 "실패 기록 초기화"로 되살려요 |
| 시각분석 응답이 JSON 이 아니에요 | 가끔 AI 가 형식을 어겨요. 다시 분석하면 대부분 돼요 |

## 8. 기획 스킬 (3단계) — "R-007로 기획해줘"

수집한 레퍼런스와 내 릴스 대본으로, 내 말투의 릴스 대본을 Claude Code 안에서 기획하는 스킬이에요. 이 폴더에서 Claude Code 를 열고 3단계 프롬프트를 붙여넣으면 설치부터 첫 기획까지 이끌어 줘요.

- 설치되는 것: `.claude/skills/릴스레퍼런스기획`, `.claude/skills/계정세팅`, `계정/_template`, `기획/`, `기획스킬_SETUP.md`
- 준비물: 내 계정 & 경쟁사 탭에 내 계정을 넣고 수집 1회. 내 상위 10개 릴스 대본이 기본으로 받아져요(10크레딧, 한 번만). 이게 내 말투(DNA) 재료예요.
- 처음 한 번 "계정 세팅해줘" → 내 릴스로 계정 문서(프로필·DNA·형식·훅·안티패턴·대표대본)를 만들어요. 중간에 세 번 확인을 물어요.
- 그 뒤로 "R-012로 기획해줘", "청소 주제로 릴스 써줘", "이번 공구 대본" → 후킹 3안 → 고르면 대본·촬영메모 → "저장"이면 `기획/` 에 저장.
- "이건 하지 마", "이 훅 추가해", "이 말투 쓰자", "대표대본 갱신"으로 계정 문서를 키워요.

스킬 원본: https://github.com/gfmmmm/reels-refs-planner (공개, 계정 정보 없음)

## 9. 파일 설명 (몰라도 됨)

```
시작.command   맥용 시작 파일
시작.bat       윈도우용 시작 파일
server.js      로컬 서버 (화면을 띄우고 요청을 받음)
collect.js     수집 프로그램 (터미널에서 node collect.js 로 단독 실행도 가능)
analyze.js     AI 분석 프로그램 (node analyze.js 전부 / node analyze.js --code 코드 한 건)
index.html     화면 전체
.env           API 키 두 개 (ScrapeCreators·Gemini. 남에게 주지 않기)
.env.example   키 자리만 비워둔 견본
data/
  config.json    기준 조회수, 내 계정, 자동 스냅샷, 채널 정체성, 자동 분석, 다음 라벨 번호, 마지막 수집·분석 요약
  accounts.json  레퍼런스 계정 목록
  competitors.json 경쟁사 목록 + 날짜별 팔로워 스냅샷 + 릴스 통계
  refs.json      수집된 릴스 (채택된 것만, 라벨·AI 분석 포함)
  seen.json      기준 미달 릴스 기록 (다음에 재판단용)
  thumbs/        썸네일 이미지 + 프로필 사진(avatar_아이디.jpg)
계정/            (3단계) 내 계정 문서 — 프로필·DNA·형식·훅·안티패턴·대표대본
기획/            (3단계) 저장한 기획안
.claude/skills/  (3단계) 기획 스킬 본체
```

데이터를 처음부터 다시 모으고 싶으면 `data/` 안의 `refs.json`, `seen.json` 을 지우고 (config.json, accounts.json, competitors.json 은 남기고) 수집을 다시 돌리면 돼요. 팔로워 추이는 competitors.json 에 쌓이니 이 파일은 지우지 마세요. 라벨 번호는 config.json 의 `nextRefNo` 를 1로 바꾸면 처음부터 다시 매겨져요.

## 10. 클라우드 자동화 (4단계) — 컴퓨터 꺼도 매일 아침 수집

4단계 프롬프트를 돌리면 역할이 셋으로 나뉘어요.

| 역할 | 어디서 | 하는 일 |
|---|---|---|
| 수집·분석 | GitHub Actions (매일 07:00) | `collect.js` → `analyze.js` 를 돌리고 결과 `data/` 를 저장소에 커밋 (`.github/workflows/daily.yml`) |
| 화면 | Vercel (정적, 보기 전용) | 커밋이 생길 때마다 `index.html` + `data/` 를 다시 올림 (`vercel.json`) |
| 설정·기획 | 내 컴퓨터 (이 폴더) | 계정·경쟁사·채널 정체성 수정, 기획 스킬. 바꾼 건 커밋·push |

- 키는 GitHub 시크릿(SCRAPECREATORS_API_KEY, GEMINI_API_KEY)에만 있어요. `.env` 는 `.gitignore` 로 올라가지 않아요. `collect.js`·`analyze.js`·`server.js` 는 `.env` 가 없으면 환경변수를 읽어요.
- 클라우드 화면은 `index.html` 의 "정적 모드"예요. `/api/status` 가 없으면 `data/*.json` 을 직접 읽고 쓰기 버튼을 전부 숨겨요. 로컬(서버 켠 화면)은 그대로예요.
- 4단계 뒤에는 로컬 설정 탭의 "수집 시작"을 누르지 마세요. 클라우드와 같은 파일을 둘이 고치면 충돌해요. 설정을 바꾸고 싶으면 Claude Code 에게 "경쟁사에 OO 추가해줘", "지금 수집 돌려줘", "최신 데이터 받아줘"라고 하세요.

- 화면 잠금은 `middleware.js`(Vercel Edge Middleware) + Vercel 환경변수 `SITE_PASSWORD`. 무료 플랜에서 되는 방법이에요. 바꾸려면 Claude Code 에게 "화면 비밀번호 바꿔줘".
